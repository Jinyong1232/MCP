# 스킬 이펙트 명세 — 순간 가속 / 무적 / 정지 / 조명탄

> 작성일 2026-09-15
> `feature-expansion.md`의 스킬(2-3) 연출 항목을 구체화한 문서다. **`feature-expansion.md`는 수정하지 않는다.**
> 이펙트는 **보이는 것만** 담당한다. 속도·피해·이동·시야 같은 실제 효과는 `SkillManager` 쪽 구현을 그대로 따른다.
> 함께 전달하는 C# 코드 3개는 시작점이다. 기존 `SkillManager` 구조에 맞춰 연결하고, 연결 방식이 이 문서와 달라지면 보고한다.

---

## 1. 파일

| 파일 | 위치 | 역할 |
|---|---|---|
| `SkillVfxLibrary.cs` | `Assets/Scripts/VFX/` | 공용 도구. 원형·고리 텍스처, 투명 머티리얼, 파티클 기본값을 코드로 생성 |
| `SkillVfxController.cs` | `Assets/Scripts/VFX/` | 플레이어에 붙임. 가속·무적·정지 이펙트 |
| `FlareVfx.cs` | `Assets/Scripts/VFX/` | 조명탄 이펙트. 호출 시 오브젝트를 만들고 끝나면 스스로 삭제 |

별도 프리팹이나 텍스처 에셋 없이 동작한다. 머티리얼 템플릿 하나만 만들어 연결하면 된다(2장).

## 2. 공통 규칙

- **머티리얼 템플릿**: `Assets/Materials/VFX/M_VFX_Particle.mat`를 URP `Particles/Unlit` 셰이더로 하나 만들어, `SkillVfxController`와 조명탄 설정의 `particleMaterialTemplate`에 연결한다. 비워두면 코드가 `Shader.Find`로 만드는데, **빌드에서는 셰이더가 빠져 이펙트가 분홍색으로 나오거나 안 보일 수 있다.** 코드는 템플릿을 복사한 뒤 투명/가산 설정을 직접 덮어쓰므로 템플릿의 세부 설정은 상관없다
- **그리는 순서**: 이펙트 머티리얼은 renderQueue 3100. 안개(3000)보다 나중에 그려져 안개에 묻히지 않는다
- **콜라이더 없음**: 기본 도형(구, 사각판)으로 만든 이펙트는 콜라이더를 제거한다. 남아 있으면 투사체나 벽 설치 클릭에 걸린다
- **레이어**: 이펙트 오브젝트는 전부 `Default`. 플레이어가 `AttackTarget` 레이어여도 자식 이펙트는 `Default`로 생성된다
- **안개**: 이펙트에 `FogVisibility`를 붙이지 않는다
- **그림자**: 모든 이펙트 렌더러는 그림자를 만들거나 받지 않는다
- **시간**: 전부 scaled time 기준. 튜토리얼 정지(`timeScale=0`) 중에는 이펙트도 멈춘다
- **크기**: 캐릭터 프리팹 스케일과 상관없이 월드 단위로 맞춘다(코드에서 스케일 보정)
- **색**: 스킬마다 색을 하나씩 정해 버튼 아이콘과 맞춘다

| 스킬 | 대표색 |
|---|---|
| 순간 가속 | 크림 화이트 `#FFF8E6` + 흙먼지 `#DBC79E` |
| 무적 | 하늘색 `#70D4FF` |
| 정지 | 호박색 `#FFC247` |
| 조명탄 | 밝은 노랑 `#FFE699` + 주황 `#FF9E40` |

## 3. 스킬별 명세

### 3-1. 순간 가속

| 요소 | 내용 |
|---|---|
| 잔상 트레일 | 캐릭터 가슴 높이(키의 45%)에서 뒤로 끌리는 흰 줄. 길이 0.3초, 폭 0.55 → 0, 가산 합성 |
| 흙먼지 | 발밑에서 이동 거리 1당 6개. 크기 0.25~0.5, 수명 0.35~0.55초, 위로 살짝 퍼지며 커졌다 사라짐 |
| 시작 고리 | 발동 순간 바닥과 평행하게 입자 16개가 사방으로 퍼짐(0.3초) |
| 종료 | 트레일·흙먼지 발생 중단. 이미 나온 입자는 자연스럽게 사라짐 |

### 3-2. 무적

| 요소 | 내용 |
|---|---|
| 보호막 | 캐릭터 몸 중앙에 반지름 0.9의 반투명 하늘색 구체. 위에서 보면 원판처럼 보인다 |
| 외곽 고리 | 보호막 가장자리에 진한 고리. 탑다운 화면에서 "막"의 윤곽 역할 |
| 발밑 빛 | 캐릭터 아래 옅은 하늘색 원 |
| 맥동 | 초당 2.5회, 크기 ±4%, 투명도 소폭 변화 |
| 시작 | 입자 18개가 구 모양으로 흩어짐 |
| 피격 무시 | `PulseShieldHit()` 호출 시 0.15초 동안 크기 +12%, 밝기 증가 |
| 종료 경고 | 끝나기 0.5초 전부터 0.08초 간격 깜빡임 (`feature-expansion.md` 2-3과 동일) |

### 3-3. 정지

| 요소 | 내용 |
|---|---|
| 원형 게이지 | 발밑 반지름 0.8의 호박색 원. 12시 방향에서 시계 방향으로 남은 시간만큼 줄어든다. 뒤에 옅은 전체 원 |
| 일시정지 아이콘 | 머리 위(높이 2.2) 흰 막대 2개 + 반투명 검은 원 배경. 위아래로 살짝 흔들림 |
| 시작 | 발밑에서 호박색 고리가 0.25초 동안 퍼지며 사라짐 |
| 회전 | 게이지와 아이콘은 캐릭터가 돌아도 회전하지 않는다 |

### 3-4. 조명탄

| 단계 | 시간 | 내용 |
|---|---|---|
| 비행 | 0.5초 | 캐릭터 위치에서 목표 지점까지 포물선(최고 높이 3). 밝은 노란 구 + 주황 후광 + 짧은 꼬리 + 작은 불똥. 높이 올라갈수록 조금 커 보이게 해서 고도감 표현 |
| 착지 | 즉시 | 섬광이 0.18초 동안 반경의 90%까지 퍼지며 사라짐. 불꽃 40개가 위로 튀었다 떨어짐 |
| 밝힘 | 3초 | 반경 5의 옅은 주황 바닥 빛 + 경계 고리, 은은한 맥동. 범위 안에서 불씨가 천천히 떠오름. 점광원(선택) |
| 페이드 | 마지막 0.5초 | 바닥 빛·고리·조명이 서서히 꺼지고 불씨 발생 중단 |
| 정리 | +2초 | 남은 입자가 사라진 뒤 오브젝트 삭제 |

- **밝힘 시간은 착지 시점부터 센다.** 착지 콜백(`onLanded`)에서 시야 원을 등록하고, 끝 콜백(`onFinished`) 또는 `SkillManager`의 자체 타이머로 해제한다. 둘 중 하나로 통일한다
- 반경과 지속시간은 이펙트에서 정하지 않는다. `SkillManager`의 조명탄 값을 그대로 넘긴다
- 바닥 빛은 안개 평면(Y 0.6)보다 살짝 위(0.62)에 그려서 안개가 걷히는 중에도 범위가 보인다
- 점광원은 URP 파이프라인 에셋의 Additional Lights가 꺼져 있으면 보이지 않는다. 바닥 빛은 조명과 무관하게 보이므로 문제는 없다. 켜져 있는지 확인만 한다

## 4. 연결 방법

### 4-1. 플레이어

`Player`(`Fox` 인스턴스)에 `SkillVfxController`를 붙이고 머티리얼 템플릿을 연결한다. 이펙트 오브젝트는 실행 시 자동으로 만들어진다.

```csharp
// SkillManager 예시 — 실제 구조에 맞게 연결
[SerializeField] SkillVfxController vfx;
[SerializeField] FlareVfx.Settings flareVfx;

void ActivateDash()   { /* 속도 배율 적용 */ vfx.PlayDash(dashDuration); }
void ActivateShield() { /* 무적 플래그   */ vfx.PlayShield(shieldDuration); }
void ActivateFreeze() { /* isStopped    */ vfx.PlayFreeze(freezeDuration); }

void ActivateFlare()
{
    Vector3 from = player.position + Vector3.up;
    Vector3 to   = /* 4타일 앞 위치 */;
    flareVfx.revealRadius   = flareRadius;
    flareVfx.revealDuration = flareDuration;
    FlareVfx.Launch(from, to, flareVfx,
        onLanded:   () => AddRevealSource(to, flareRadius),
        onFinished: () => RemoveRevealSource(to));
}
```

### 4-2. 무적 중 피격

`PlayerHealth`에서 무적 때문에 피해를 0으로 만든 순간 `vfx.PulseShieldHit()`를 호출한다.

### 4-3. 효과가 중간에 끊길 때

스킬 효과가 예정보다 먼저 끝나면(사망, 결과 화면 등) 해당 `Stop…()`을 호출한다.

### 4-4. 재도전

`RetryStage` 초기화 때 `vfx.StopAll()`과 `FlareVfx.ClearAll()`을 호출한다. `ClearAll`은 콜백을 부르지 않으므로 시야 원 정리는 `SkillManager` 초기화에서 따로 한다.

## 5. 검증

- [ ] 콘솔 에러·경고 없음(특히 셰이더를 찾지 못했다는 경고)
- [ ] 스킬 4종 각각 발동 → 이펙트 표시 → 지속시간 뒤 사라짐
- [ ] 가속: 캐릭터 뒤 트레일, 발밑 먼지. 종료 후 먼지 발생이 멈춤
- [ ] 무적: 끝나기 0.5초 전 깜빡임. 무적 중 피격 시 번쩍임
- [ ] 정지: 게이지가 12시에서 시계 방향으로 줄어듦. 캐릭터가 방향을 틀어도 게이지·아이콘이 돌지 않음
- [ ] 조명탄: 포물선 비행 → 섬광 → 3초 밝힘 → 페이드 → 오브젝트 삭제(Hierarchy에서 `VFX_Flare`가 사라짐)
- [ ] 조명탄 밝힘이 실제 시야 원 등록·해제 시점과 일치
- [ ] 가속 + 무적 동시 사용 시 둘 다 정상 표시
- [ ] 튜토리얼 정지 중 이펙트가 멈추고, 재개 시 이어서 진행
- [ ] 이펙트가 벽 설치 클릭이나 투사체에 걸리지 않음
- [ ] 이펙트가 안개에 묻히지 않음
- [ ] 재도전 시 모든 이펙트가 즉시 사라짐
- [ ] Play 모드 종료 후 머티리얼 에셋(`M_VFX_Particle`)이 변하지 않음
- [ ] 스크린샷: 스킬별 1장씩(탑다운 카메라 화면)

## 6. 조정 포인트

대부분의 수치는 `SkillVfxController` 인스펙터와 `FlareVfx.Settings`에서 바로 바꿀 수 있다.

| 문제 | 조정 |
|---|---|
| 트레일이 너무 길거나 짧음 | `dashTrailTime`, `dashTrailWidth` |
| 보호막이 캐릭터를 다 가림 | `shieldRadius` 키우기, 또는 코드의 채움 투명도(0.16) 낮추기 |
| 게이지가 캐릭터에 가려짐 | `freezeGaugeRadius` 키우기 |
| 아이콘이 카메라 밖으로 나감 | `freezeIconHeight` 낮추기 |
| 조명탄 범위가 잘 안 보임 | 코드의 바닥 빛(0.3)·경계(0.55) 투명도 올리기 |
| 캐릭터 키와 이펙트 높이가 안 맞음 | `characterHeight` |
